Mammoth 0.1.21

- Connect a song folder and rescan .mampak packs, unpacked song folders and ordinary MIDI files in the background.
- One Library row per composition, with separate actual difficulty arrangements and Melody, Accompaniment, Complete and Recall masteries. Authored assets and explicit hands are retained.
- Progress follows musical revisions; repeated imports, equivalent copies, metadata changes and folder relocation preserve compatible scores. Broken updates retain the working cached song.
- Follow notes is a default-on toggle independent of zoom. Added song width-and-height fit while retaining whole-song view.
- Compact hover menus with labelled sliders, larger attached Play/Learn/Create tabs, aligned navigation and proper Settings/Career icons.
- Library difficulty tabs, left-side search/style controls, clearer information, larger personal best scores and Mammoth cover marks.
- Subtle playback section labels and a pause-to-Learn chord link with nearby observed harmonies and teaching sources.
- Dynamic note atomization with density, lifetime and glow controls; optional estimated fingering and keyboard note names; reversible wheel direction.
- Separate advanced Create Editor with Alt/mouse navigation, drag selection and snapping; overlapping Create actions fixed.
- Expanded Career statistics and a new 72-bar original, The Long Way Home.

Existing songs, settings, Recall recordings and progress are retained. Hello Day is a separate integration song pack and is not bundled in this update. Generated practice versions and fingering remain estimates; optional per-song presentation references are established but render with Mammoth defaults. Historical musical revisions remain stored; a full revision-history browser is not included yet.
